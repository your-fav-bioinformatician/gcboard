# Terminal tic-tac-toe

Build a two-player tic-tac-toe game that runs in the terminal.

## Requirements

- Draw the 3x3 board after every move.
- Players take turns entering a cell; reject occupied or invalid cells.
- Detect a win (row, column, diagonal) and a draw.
- Offer a rematch when a game ends.

## Stretch goals

- A computer opponent that never loses (minimax).
- Board sizes other than 3x3.

Any language the identifier extractor supports works. Start from an empty
public repository and commit as you go.
